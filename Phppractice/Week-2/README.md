// Do While Loop

Wuxuu xisaabinayaa factorial-ka lambarka 5 (5!). Wuxuu fuliyaa koodka ugu yaraan hal mar ka dibna wuxuu hubiyaa shuruudda inta $n > 0.

//Break Statement   

Wuxuu socodsiiyaa while loop ilaa 15. Si kastaba ha ahaatee, wuxuu leeyahay shuruud ah in haddii $i ay noqoto 10, uu amarka break joojinayo loop-ka isla markiiba. 

Continue Statement   

Wuxuu  skip gareyna lambarka hadda taagan marka uu yahay mid laba-laba u qaybsama (even number) iyadoo la adeegsanayo amarka continue, halka lambarrada kale uu daabacayo.

//Nested Loops 

Wuxuu ka kooban yahay laba for loop oo isku dhex jira mid safafka ah iyo mid tiirarka ah si loo soo saaro miiska isku-dhufashada Multiplication table ee 1 ilaa 12.

//Numerically Indexed Arrays   
Wuxuu muujinayaa sida loo abuuro array lambarro index ah leh sida 0, 1, 2 iyo sida si toos ah loogula soo dhex baxo qiimaha adigoo adeegsanaya index-kiisa tusaale: $fruits[0].

//Adding items without explicit locations & Displaying arrays
Wuxuu ku darayaa xubno cusub oo ah miro Apple, Orange, Banana adigoo aan cayimin lambarka index-ka. Wuxuu adeegsanayaa print_r($fruits) si uu u soo bandhigo qaab-dhismeedka arrayga.

//Printing Associative Array Elements

Wuxuu adeegsanayaa foreach loop si uu u soo saaro furayaasha ($k) iyo qiimayaasha $v ee ku jira array-ga xogta qofka $info.  

//Associative Arrays   
Wuxuu abuurayaa array ay xubnihiisu leeyihiin magacyo ama furayaal gaar ah id, name, age, address, status, weight iyadoo la adeegsanayo calaamadda =>.

//Adding Array Elements using Loop
Wuxuu isticmaalayaa foreach loop si uu isugu daro dhammaan qiimayaasha ku jira array-ga $numbers (10 + 10 + 15), kadibna wuxuu soo bandhigayaa wadarta guud.
