# PHP Arrays and Functions – Concepts

## 1. Multi-dimensional Array
Array ka kooban arrays kale. Waxaa lagu kaydiyaa xog isku xiran.

## 2. foreach
Loop lagu dhex maro elements-ka array-ga mid mid.

## 3. Nested foreach
`foreach` ku dhex jira `foreach` kale. Waxaa lagu isticmaalaa multi-dimensional arrays.

## 4. is_array()
Waxaa lagu hubiyaa in variable-ku yahay array iyo in kale.

## 5. in_array()
Waxaa lagu hubiyaa in value gaar ah uu ku jiro array.

## 6. explode()
String ayuu u kala qaybiyaa qaybo, kadibna wuxuu ka dhigaa array.

## 7. shuffle()
Elements-ka array-ga si random ah ayuu u kala habeeyaa.

## 8. array_merge()
Laba ama ka badan arrays ayuu isku daraa.

## 9. array_reverse()
Order-ka elements-ka array-ga ayuu dib u rogaa.

## 10. array_push()
Element cusub ayuu ku daraa dhammaadka array-ga.

## 11. array_pop()
Element-ka ugu dambeeya ayuu ka saaraa array-ga.

## 12. end()
Element-ka ugu dambeeya ee array-ga ayuu soo helaa.

## 13. Function
Qayb code ah oo qabata shaqo gaar ah, lana isticmaali karo marar badan.

## 14. Function Parameter
Variable xog lagu geliyo function-ka.

## 15. return
Natiijo ayuu function-ka dib uga soo celiyaa.

## 16. Factorial
Number-ka waxaa lagu dhuftaa dhammaan numbers-ka ka bilaabma 1 ilaa number-kaas.

## 17. for Loop
Code ayuu ku celceliyaa tiro ama xaalad cayiman.

## 18. print_r()
Waxaa lagu muujiyaa xogta array-ga qaab la fahmi karo.
Summary

The screenshots in this folder demonstrate the following PHP concepts:

| PHP Concept             | Purpose                              |
| ----------------------- | ------------------------------------ |
| Multi-dimensional Array | Stores arrays inside another array   |
| `foreach`               | Loops through array elements         |
| `is_array()`            | Checks if a variable is an array     |
| `in_array()`            | Checks if a value exists in an array |
| `explode()`             | Converts a string into an array      |
| `shuffle()`             | Randomly changes array order         |
| `array_merge()`         | Combines arrays                      |
| `array_reverse()`       | Reverses an array                    |
| `array_push()`          | Adds an element to an array          |
| `array_pop()`           | Removes the last element             |
| `end()`                 | Gets the last element                |
| `function`              | Creates reusable code                |
| `return`                | Returns a value from a function      |
| Factorial               | Demonstrates loops and functions     |


Conclusion

These examples provide a basic understanding of PHP Arrays and Functions. They demonstrate how PHP can store, manipulate, and process data using arrays and reusable functions.
